The strip Program

Send one mining turtle down a spine tunnel that throws off ribs to the left and right at a fixed spacing — the classic strip mine — and have it chase down every ore vein it uncovers along the way.

Command: strip <length> [ribReach] [spacing] [height] Turtles: 1 (standalone) Modem: not required Pattern: branch.lua

1What strip does

strip is the single-turtle driver for the branch/strip pattern. Where dig clears one straight box, strip cuts a long spine and hangs ribs off both sides of it — far more ore exposed per block dug. It does four jobs:

Cuts the spine

A 1-wide corridor running forward for length cells, the trunk everything else hangs off.

Cuts paired ribs

At every multiple of spacing it turns off and cuts a rib right and a rib left, each reaching ribReach blocks out, then rejoins the spine.

Follows ore veins

Every face it exposes gets checked. Find an ore block and it leaves the corridor, mines the whole connected vein, and comes back to the exact block it left from.

Lights, patches & returns

Torches along the spine, filler over floor gaps, loot streamed into an Ender Chest — then home to the mouth facing its original direction.

Standalone — no fleet needed

strip is one turtle doing one job; it doesn't use rednet or the control station at all. (The branch pattern isn't wired into the fleet yet — that's a later step. For multi-turtle box clears, use mine / the control station.)

2What you need

ItemWhy
1× Mining TurtleAny Mining Turtle. An Advanced one gives coloured output. No modem required.
Plenty of fuelCoal / charcoal in a slot, then refuel all. A strip mine covers far more ground than a tunnel, and vein chasing adds more on top — strip prints its estimate and tops up automatically if it can.
Ender Chest (strongly recommended)One in slot 16. Vein following fills an inventory fast; without a chest the overflow drops on the ground.
Torches (optional)A stack in slot 15 to light the spine as it goes.
Filler blocks (optional)Cobblestone (or any cheap block) in slot 14 to bridge gaps in the floor.

Everything optional only engages if it's actually stocked — an empty slot just means that feature is skipped, and strip tells you which ones are on before it starts.

3Get the code in-game

The turtle needs the project files. Bootstrap once with update.lua, then re-run update after any change.

  1. On a fresh turtle, pull the updater once: 
    > wget https://raw.githubusercontent.com/cpopson/ATM10-miningTurtles/master/update.lua update.lua
> update
  2. After every push to GitHub, just run update again.

4Geometry — place it right

Everything is measured relative to how the turtle faces when you start it. The turtle stands in the spine mouth — its own block is never dug — and the mine grows:

DimensionDirection
length (1st number)Forward — the way the turtle is facing. Counted in cells including the mouth it starts on.
ribReach (2nd number)How far each rib runs out from the spine — the same distance to the left and to the right.
spacing (3rd number)Spine cells between one rib pair and the next. A pair sits at every multiple of this, starting at spacing itself (never at the mouth).
height (4th number)Straight up, for the spine and every rib alike.

Why spacing 3?

Ribs 3 apart leave a 2-block wall between them, and every block of that wall touches a rib — so no vein can hide in it. Tighter spacing digs more stone for the same ore; wider spacing starts missing veins. 3 is the classic ratio, and it's the default.

Defaults

Give just a length and you get 8-block ribs every 3 cells, 2 tall, using ribReach and ribSpacing from config.lua. Pass 0 for ribReach to get a plain vein-following tunnel with no ribs at all.

Bring an Ender Chest

Vein following means the turtle mines far more than the corridor itself. Without a chest in slot 16 a long run will overflow and start dropping ore on the ground. Torches need headroom too — a height 1 mine skips them entirely.

6Run it

  1. Place the turtle in the spine mouth, facing the direction you want the spine to run.
  2. Load fuel and any optional slots (section 5), then refuel all.
  3. Run strip with a length, and optionally rib reach, spacing and height: 
    > strip <length> [ribReach] [spacing] [height]

A typical lit, floor-patched strip mine with a 40-long spine:

> strip 40
Ender Chest in slot 16 - will auto-dump loot when full.
Torches in slot 15 - one on the spine every 8 blocks.
Filler in slot 14 - floor gaps will be patched.
Vein following ON (sides, max 64 blocks per vein).
  Side scanning roughly triples wall-clock time (fuel cost is unchanged).
  Set veinScan = "vertical" in config.lua to speed it up.
Strip mining: spine 40 long, 13 rib pair(s) every 3, reaching 8 each side, 2 tall...
DONE: 521 cells, 26 ribs, 63 ore from 14 veins (4 torches, 31 fills, 3 dumps), back at start.
ExampleResult
strip 40Spine 40 long, 8-block ribs every 3 cells, 2 tall. The default strip mine.
strip 60 12 4A bigger field: 12-block ribs every 4 cells off a 60-long spine.
strip 30 6 3 3Same layout, 3 tall — more headroom, ~50% more digging.
strip 24 0No ribs: a plain 24-long tunnel that still chases every vein it exposes.

7Reading the output

Before it starts, strip prints one line per optional feature so you can confirm what's on. When it finishes it prints one of two lines:

Success

DONE: 521 cells, 26 ribs, 63 ore from 14 veins (4 torches, 31 fills, 3 dumps), back at start.
  • cells — corridor blocks the turtle moved through (spine plus every rib). Vein detours are not counted here.
  • ribs — individual ribs finished, so a full run is twice the pair count.
  • ore / veins — ore blocks mined off-corridor, and how many separate veins they came from.
  • torches / fills / dumps — torches placed, floor gaps patched, and loot dumps made.
  • back at start — it returned to the mouth block, facing its original heading.

Two extra lines appear only when they apply:

  2 vein(s) hit the 64-block cap - raise maxVein in config.lua to finish them.
  5 vein(s) skipped to conserve fuel.

Aborted

ABORTED (no_fuel) after 188 cells, 8 ribs, 24 ore.
  stopped at (6,0,-14) h=0 relative to start.

It stops cleanly and tells you where. Common reasons:

ReasonMeaning
no_fuelRan out of fuel. Refuel and re-run (it re-cuts from the mouth; already-dug cells cost only a move).
blocked_unbreakableHit bedrock or another unbreakable block in the spine or a rib.
blocked_retry_exceededSomething kept refilling the space (falling gravel/sand past the retry budget).
dump_place_failedCouldn't place the Ender Chest to dump (obstruction above). Rare.
abortedSomething asked it to stop. Only happens under fleet control, not from strip.
pose lost mid-vein

If the abort line is followed by "WARNING: pose lost mid-vein", the turtle ran dry while walking back out of a vein, so it is somewhere off the corridor rather than on it. The stopped at coordinates are still correct — go fetch it before re-running.

8Tuning (config.lua)

The rib layout, vein behaviour and reserved slots all live in config.lua. Change a value, run update, and it takes effect.

KeyDefaultControls
ribReach8How far each rib runs out from the spine, per side.
ribSpacing3Spine cells between rib pairs.
veinFollowtrueMaster switch for chasing exposed ore.
veinScan"sides"Which faces get checked — see the table below.
maxVein64Most ore blocks mined from any one vein, so a huge deposit can't swallow the run.
chestSlot16Slot the Ender Chest lives in.
torchSlot15Slot the torches live in.
fillerSlot14Slot the filler blocks live in.
torchEvery8Blocks between torches along the spine.

Choosing a veinScan

ValueFaces checkedCost
"sides"Floor, ceiling and both walls — complete coverage; nothing the dig exposes is missed.~3× the wall-clock time of a blind dig.
"vertical"Floor and ceiling only.No overhead at all.
"none"Nothing — ribs are cut blind.No overhead at all.
Turning is free

Checking the walls means turning, and turning costs no fuel — only time. So veinScan trades wall-clock minutes, never range: a "sides" run and a "none" run of the same size need the same fuel for their corridors.

Keep the slots contiguous

The reserved slots sit at the top of the inventory so the loot region below them stays contiguous. If you move one, keep the trio together (e.g. 16/15/14) so loot never spills into a reserved slot.

9Troubleshooting

SymptomFix
"usage: strip …" and nothing runsYou didn't give a length. The first number is required: strip 40.
"Low fuel…" and it stopsAdd coal/charcoal and refuel all. The estimate includes a vein-following allowance, so it asks for noticeably more than dig would.
It's crawlingveinScan = "sides" turns four times per block. Set it to "vertical" for a big speed-up at the cost of wall veins.
Ore is being walked pastEither veinFollow is off / veinScan is "none", or fuel dropped below the vein reserve (look for "skipped to conserve fuel"). A modded ore with an unusual name and no ore tag can also be missed — pass your own oreMatch if so.
No ribs were cutspacing is larger than length - 1, so no rib position fits. strip warns about this and cuts a plain tunnel instead.
Ribs merged into one big roomspacing 1 puts a rib pair on every spine cell, leaving no wall between them — that's an excavation, not a strip mine. Use 3 (strip warns when you pass 1).
Mine is darkNo torches in slot 15, or height 1. Stock slot 15 and use height ≥ 2. (Ribs are unlit by design — only the spine gets torches.)
Loot dropped on the groundNo Ender Chest in slot 16. With vein following on, this fills up fast — add one.
Turtle stopped partwayRead the ABORTED (reason) line (section 7). Usually fuel or an unbreakable block.
